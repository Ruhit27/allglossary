"The cloud" means someone else's computers, in huge data centers, that you rent by the hour or by usage instead of buying your own. Amazon Web Services, Google Cloud and Microsoft Azure are the biggest providers. You can rent raw [servers](./Server.md), [databases](./Database.md), storage, [CDNs](./Content%20delivery%20network%20%28CDN%29.md) and much more.

The appeal is flexibility. You can start small, grow when traffic spikes, and stop paying when you stop using something. Many [hosting](./Hosting.md) platforms are themselves built on top of the big clouds.

The flip side is cost and complexity: bills can grow unexpectedly, and the number of options is overwhelming.

_Avoid:_ assuming "in the cloud" means it can't break — cloud services go down too, just less often.

_Usage:_

"Our cloud bill tripled this month."

"A test server was left running at full size. Let's shut it down and set a spending alert."
