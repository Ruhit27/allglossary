description: The language that controls how a web page looks: colors, fonts, spacing and layout.
---

Cascading Style Sheets. CSS is a set of rules like "all headings are dark blue" or "this menu sits on the left on wide screens". It takes the structure from [HTML](./HTML.md) and decides how it appears: colors, sizes, fonts, spacing, layout, animations.

Keeping looks separate from content means one stylesheet can restyle a whole [website](./Website.md). "Cascading" refers to how rules combine when several apply to the same element — more specific rules win over general ones, which is a common source of "why won't my style apply?" puzzles.

CSS is also what makes [responsive design](./Responsive%20design.md) possible: rules can change depending on screen size, so the same page works on a phone and a large monitor.

_Avoid:_ "CSS" as only colors and fonts — it also controls layout, spacing and how pages adapt to screen size.

_Usage:_

"Every button on the site is a slightly different blue."

"Let's define the brand blue once in the CSS and make all buttons use it."
