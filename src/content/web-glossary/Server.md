---
description: A computer that stores websites or data and sends them out when asked.
---

A computer, usually in a data center, that waits for [requests](./Request%20and%20response.md) and answers them. When your [browser](./Browser.md) asks for a page, a server finds or builds it and sends it back. One physical machine can act as many servers, and big sites use thousands.

The word means two things: the hardware, and the [web server](./Web%20server.md) software running on it that handles requests. Either way, it's the other end of every page you load — the [client](./Client.md) asks, the server answers.

Most people don't run their own servers anymore. They rent space through [hosting](./Hosting.md) or the [cloud](./Cloud.md), where someone else keeps the machines running.

_Avoid:_ "server" as somewhere special and mysterious — it's just a computer whose job is answering requests.

_Usage:_

"Why is the site down? Did we break the code?"

"The code's fine. The server ran out of disk space, so it stopped answering requests."
