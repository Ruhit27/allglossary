---
description: The app you use to open and view web pages, such as Chrome, Safari, Firefox or Edge.
---

A browser fetches [web pages](./Web%20page.md) and turns their code into what you see. You give it a [URL](./URL.md); it finds the [server](./Server.md) through [DNS](./Domain%20Name%20System%20%28DNS%29.md), sends a [request](./Request%20and%20response.md) using [HTTP](./HTTP.md), then reads the [HTML](./HTML.md), [CSS](./CSS.md) and [JavaScript](./JavaScript.md) that come back and draws the page.

The browser is the web's [client](./Client.md). It also keeps things for you between visits — [cookies](./Cookie.md), saved logins, a [cache](./Cache.md) of files it's already downloaded — and enforces safety rules so one site can't read another site's data.

Different browsers use different engines to draw pages, so a page can look or behave slightly differently in each. Web developers test in several browsers for that reason.

_Avoid:_ "browser" and "search engine" as the same — Chrome is a browser; Google is a website you open in it.

_Usage:_

"The checkout button doesn't work for one customer."

"Ask which browser they use. If it's an old one, that might explain it."
