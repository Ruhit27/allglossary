---
description: The programming language that runs in the browser, making web pages interactive.
---

The only programming language every [browser](./Browser.md) runs. While [HTML](./HTML.md) gives a page structure and [CSS](./CSS.md) gives it style, JavaScript makes it do things: open a menu, check a [form](./Form.md) before it's sent, load new posts as you scroll, update a cart without reloading.

JavaScript works by reading and changing the [DOM](./DOM.md), the browser's live version of the page. It can also send [requests](./Request%20and%20response.md) to an [API](./API.md) in the background and show the results. Most [frameworks](./Framework.md) are written in it, and with tools like Node.js it can run on a [server](./Server.md) too.

Too much JavaScript slows sites down, especially on cheaper phones, since it all has to be downloaded and run. Good [web performance](./Web%20performance.md) means using only what's needed.

_Avoid:_ confusing JavaScript with Java — they're unrelated languages with an unlucky naming history.

_Usage:_

"The page is blank until it loads for ages."

"It's shipping a huge JavaScript file before showing anything. Let's split it up."
