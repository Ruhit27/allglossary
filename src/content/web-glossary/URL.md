description: The address of a resource on the web, such as https://example.com/about.
---

Short for Uniform Resource Locator: the full address of a [web page](./Web%20page.md) or file. Take https://example.com/shop/shoes?size=9. It has a scheme (https, meaning use [HTTPS](./HTTPS.md)), a [domain name](./Domain%20name.md) (example.com), a path (/shop/shoes) pointing to a specific page, and an optional query (?size=9) carrying extra details.

Every [hyperlink](./Hyperlink.md) is a URL. When you type one into a [browser](./Browser.md), the browser finds the right [server](./Server.md) using the domain name and asks it for the path.

Good URLs are readable and stable. If a page moves and its old URL stops working, every link pointing to it breaks — which is why sites set up redirects when they reorganize.

_Avoid:_ "URL" and "domain" as the same — the domain is just one part of the URL.

_Usage:_

"I shared the link but it opens the home page."

"You copied the domain only. Copy the full URL from the address bar, including the path."
