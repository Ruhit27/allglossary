---
description: The part of a web page where you type or choose information and send it, like a login or checkout.
---

Text boxes, checkboxes, dropdowns and a submit button: a form collects information from a visitor. Built with [HTML](./HTML.md) form elements, it sends what you entered to a [server](./Server.md), usually with an [HTTP](./HTTP.md) POST [request](./Request%20and%20response.md).

Forms power sign-ups, searches, [logins](./Login.md), comments and checkouts. [JavaScript](./JavaScript.md) can check entries before they're sent ("that email address looks incomplete"), but the server must check them again — anything from the [client](./Client.md) can be faked.

Good forms are short, label every field clearly, explain errors in plain words, and work with a keyboard. Each of these is part of [accessibility](./Accessibility.md).

_Avoid:_ "form" as only a long questionnaire — a search box and a login box are forms too.

_Usage:_

"People keep abandoning the sign-up form."

"It has eleven fields. Let's cut it to email and password and ask for the rest later."
