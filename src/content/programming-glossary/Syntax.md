---
description: The grammar rules of a programming language: how code must be written to be understood.
---

Every [programming language](./Programming%20language.md) has strict rules for spelling and punctuation — where brackets go, how lines end, which words are reserved. That's syntax. In Python, indentation matters; in JavaScript, curly braces mark blocks of code.

Break the rules and you get a syntax [error](./Error.md): the computer refuses to run the code at all, and points (sometimes vaguely) to where it got confused. Unlike people, a [compiler](./Compiler.md) or [interpreter](./Interpreter.md) won't guess what you meant.

Syntax is the easy part of programming to learn — and the easiest to get help with, since [IDEs](./IDE.md) underline mistakes as you type. The hard part is the logic.

_Avoid:_ "syntax" for what code means — syntax is how it's written; what it does is a separate question.

_Usage:_

"It just says 'unexpected token' on line 40."

"That's a syntax error. Look for a missing bracket or comma just before that line."
