description: A step-by-step method for solving a problem, which can be turned into code.
---

An algorithm is a recipe: a precise list of steps that always ends with an answer. "To find a name in a sorted phone book, open it in the middle; if the name comes earlier, repeat with the first half, otherwise the second half" is an algorithm (called binary search). It exists before any [code](./Code.md) — you could follow it with paper.

Programmers choose algorithms by how much work they take as the data grows. Checking every name one by one is fine for ten names but painfully slow for ten million; binary search needs only about 24 steps for ten million. Algorithms work hand in hand with [data structures](./Data%20structure.md), which organize the data they operate on.

In the news, "the algorithm" usually means the rules a platform uses to rank posts — a specific, very complicated example of the idea.

_Avoid:_ "algorithm" as something mysterious or always AI — it's any precise set of steps, as ordinary as a recipe.

_Usage:_

"Sorting the customer list takes forever."

"We're using a simple algorithm that's fine for small lists. A better one would finish in seconds."
