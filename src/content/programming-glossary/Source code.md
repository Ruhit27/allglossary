---
description: The original, human-readable code of a program, as its programmers wrote it.
---

Source code is the full set of [code](./Code.md) files written by people in a [programming language](./Programming%20language.md). It's the "recipe" for a [program](./Program.md). To actually run, it usually goes through a [build](./Build.md) that turns it into something the computer executes directly.

Source code is valuable: whoever has it can change the program. Companies often keep theirs private; open source projects publish theirs so anyone can read and improve it. Teams store it in [version control](./Version%20control.md) so every change is recorded.

When people say "look at the source", they mean read the code itself, not just use the finished program.

_Avoid:_ "source code" as the running program — the source is the recipe; the program is what you get after building it.

_Usage:_

"Can we fix this bug in the app ourselves?"

"Only if we have the source code. Right now we only have the finished program."
