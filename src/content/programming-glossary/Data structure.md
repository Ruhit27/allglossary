---
description: A way of organizing data in a program so it can be used efficiently.
---

A data structure is a shape for data. An [array](./Array.md) keeps items in order; a [dictionary](./Dictionary.md) finds them by label; a queue serves items first-in, first-out, like a line at a shop; a tree organizes them in branches, like folders on a computer.

The right structure makes a program fast and simple; the wrong one makes it slow and awkward. Finding one name in an unsorted list means checking each item in turn, while a dictionary can jump straight to it. Choosing a data structure goes hand in hand with choosing an [algorithm](./Algorithm.md).

Most [programming languages](./Programming%20language.md) include the common structures built in, so programmers rarely build them from scratch — but knowing which to pick is a core skill.

_Avoid:_ "data structure" meaning a database layout — it's how data is arranged inside a running program.

_Usage:_

"Checking whether a user is banned takes ages."

"We search a list of a million IDs each time. A set would answer instantly."
