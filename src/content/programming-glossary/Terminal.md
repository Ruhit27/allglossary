description: A text window where you control the computer by typing commands instead of clicking.
---

The terminal (also called the command line, console or shell) is a window where you type instructions like `cd projects` (go into the projects folder) or `npm install` (fetch a project's [dependencies](./Dependency.md)) and press Enter. The computer prints a response as text.

Programmers use it constantly because many tools only exist as commands: [package managers](./Package%20manager.md), [version control](./Version%20control.md), [build](./Build.md) tools, test runners. Commands can be saved and combined into scripts that automate repetitive work. Most [IDEs](./IDE.md) include one.

It looks intimidating, but most daily use is a handful of commands. Be careful with commands copied from the internet, though: the terminal does exactly what you say, including deleting files.

_Avoid:_ "terminal" as something only hackers use — it's an everyday tool for most programmers.

_Usage:_

"How do I start the project?"

"Open the terminal in the project folder and run the start command from the readme."
