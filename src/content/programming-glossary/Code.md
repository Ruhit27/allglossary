---
description: The written instructions that make up a program, in a programming language.
---

Code is text — lines of instructions like `total = price * quantity` — written in a [programming language](./Programming%20language.md). Writing it is called coding or programming. All the code for a [program](./Program.md) together is its [source code](./Source%20code.md).

Code is read far more often than it's written, by other people and by your future self. Clear names, small pieces, and the occasional [comment](./Comment.md) explaining why make it much easier to change later. [Code review](./Code%20review.md) exists so someone else checks it before it goes live.

Code has to follow the language's [syntax](./Syntax.md) exactly. A missing bracket that a human would shrug off stops the computer entirely.

_Avoid:_ "a code" for a program — programmers say "some code" or "the code"; "a code" sounds like a password or cipher.

_Usage:_

"How long will this feature take?"

"Writing the code is quick. Testing it and making sure it doesn't break anything else takes longer."
