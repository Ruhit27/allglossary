---
description: A named place in a program that holds a value, which can change as the program runs.
---

A variable is a labeled box. `age = 36` puts the value 36 in a box called age; later code can read it, or replace it with `age = 37`. Variables let a [program](./Program.md) remember things while it runs — a user's name, a running total, how many tries are left.

Every value has a [data type](./Data%20type.md): a number, a piece of text (a [string](./String.md)), true or false (a [boolean](./Boolean.md)), a list (an [array](./Array.md)). Where in the code a variable can be used is its [scope](./Scope.md).

Good variable names say what's inside: `unpaid_invoices` beats `x`. Clear names are one of the cheapest ways to make [code](./Code.md) easier to understand.

_Avoid:_ "variable" meaning the value always changes — many hold one value for their whole life; it's the name that matters.

_Usage:_

"What's this variable called 'temp2' for?"

"No idea. Let's rename it to say what it holds."
