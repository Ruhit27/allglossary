---
description: A precise, written language for giving instructions to a computer, such as Python, JavaScript or Java.
---

Computers only truly understand very low-level instructions — patterns of ones and zeros. Programming languages let people write instructions in something closer to English and maths, which a [compiler](./Compiler.md) or [interpreter](./Interpreter.md) then turns into what the machine runs.

There are hundreds. Python is popular for beginners, data and AI; JavaScript runs in web browsers; Java and C# power many business systems; C and Rust are used where speed matters most. Each has its own [syntax](./Syntax.md), but most share the same core ideas: [variables](./Variable.md), [conditions](./Condition.md), [loops](./Loop.md) and [functions](./Function.md).

Once you've learned one language, the next is much easier, because the ideas carry over even when the spelling changes.

_Avoid:_ "which language is best?" — each is designed for different jobs; the best one depends on what you're building.

_Usage:_

"Should I learn Python or JavaScript first?"

"Either is fine. Pick the one for what you want to build — data and automation, or websites."
