---
description: Integrated Development Environment: an app for writing code, with editing, running and debugging tools in one place.
---

An IDE is a programmer's workshop. Beyond typing text, it colors [code](./Code.md) to make it readable, underlines [syntax](./Syntax.md) mistakes as you type, suggests completions, jumps to where a [function](./Function.md) is defined, and runs a debugger for [debugging](./Debugging.md). Popular ones include Visual Studio Code, IntelliJ IDEA and Xcode.

Most IDEs also include a built-in [terminal](./Terminal.md) and connect to [version control](./Version%20control.md), so much of a programmer's day happens in one window. Many now offer AI assistants that suggest code too.

You don't need an IDE to program — any text editor works — but it saves a lot of time and catches mistakes early.

_Avoid:_ "IDE" and "programming language" as the same — the IDE is the app you write code in; the language is what you write.

_Usage:_

"I keep making typos in variable names."

"Your IDE can autocomplete them. Turn on suggestions and it'll catch most of those."
