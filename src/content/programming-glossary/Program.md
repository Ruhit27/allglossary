---
description: A set of instructions a computer follows to do a job.
---

A program is a list of precise instructions: "take this number, add that one, show the result". Apps on your phone, websites, games, the software inside a washing machine — all programs. A computer does nothing useful without one.

People write programs as [code](./Code.md) in a [programming language](./Programming%20language.md). Before the computer can follow it, the code is usually translated by a [compiler](./Compiler.md) or run by an [interpreter](./Interpreter.md). Behind many programs is an [algorithm](./Algorithm.md): the step-by-step method for solving the problem.

Computers follow instructions exactly, never guessing what you meant. A program that does the wrong thing is almost always doing precisely what it was told — that's a [bug](./Bug.md).

_Avoid:_ "program" and "app" as different things — an app is just a program made for people to use directly.

_Usage:_

"The computer did something weird."

"It did exactly what the program told it to. We need to find which instruction was wrong."
