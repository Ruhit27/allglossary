description: A single complete instruction in a program, like one sentence in a recipe.
---

A statement tells the computer to do one thing: store a value in a [variable](./Variable.md) (`total = 0`), show a message, call a [function](./Function.md). A [program](./Program.md) is largely a sequence of statements, run one after another from top to bottom.

Some statements control the order of others. A [condition](./Condition.md) decides whether a group of statements runs at all; a [loop](./Loop.md) repeats a group. Statements often contain [expressions](./Expression.md) — pieces that work out a value, like `price * 2`.

Each [programming language](./Programming%20language.md) has its own [syntax](./Syntax.md) for ending statements — a new line in Python, often a semicolon in JavaScript or Java.

_Avoid:_ "statement" and "expression" as the same — an expression works out a value; a statement does something.

_Usage:_

"Why is the discount applied twice?"

"There's a duplicate statement on line 52 that adds it again."
